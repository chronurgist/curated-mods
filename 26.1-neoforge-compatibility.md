# ATM-lite-lite: Minecraft 26.1 NeoForge compatibility

_Checked 2026-08-30. A compatible file means a publisher Modrinth release tagged both `26.1.x` and `neoforge`; it does **not** prove the complete pack launches together._

## Verdict

**Do not build this as a production 26.1 pack yet.** Many core mods are available, but important progression/content mods have no 26.1 NeoForge release and several available builds are alpha/beta. A 1.21.1 NeoForge pack is the stable choice; 26.1 is an experimental porting project.

## Available for 26.1 NeoForge

- **Infrastructure:** Ender IO (alpha), AE2 (beta), AE2 Wireless Terminals (beta), Entangled, Functional Storage, Iron Furnaces, Powah (alpha), GeckoLib.
- **Resources/progression:** Mystical Agriculture, Item Collectors, Trash Cans, Apotheosis, Artifacts.
- **Food/utility:** Cooking for Blockheads, Sophisticated Backpacks, Easy Villagers, Waystones, Comforts, Carry On, Simple Magnets, Crafting Table on a Stick, FramedBlocks, Connected Glass.
- **UI/navigation:** JEI, Just Enough Resources, Jade, Crafting Tweaks, Inventory Profiles Next, Shulker Box Tooltip, Mouse Tweaks, Searchables, AttributeFix, BetterF3, Better Advancements, Legendary Tooltips, Item Borders, Enchantment Descriptions, AppleSkin, Controlling, Just Zoom, Dark Mode Everywhere, Colorful Hearts, Toast Control, NetherPortalFix, JourneyMap, Nature's Compass, Explorer's Compass.
- **Worldgen:** Dungeon Crawl; YUNG's API, Better Dungeons, Better Mineshafts, Better Nether Fortresses, and Better Ocean Monuments.
- **Rendering/performance:** Sodium (alpha), Sodium Extra, Iris, ImmediatelyFast, FerriteCore, ServerCore, FastSuite, FastWorkbench, FastFurnace, AI Improvements, Let Me Despawn, Clumps, spark, Entity Culling, More Culling, Dynamic FPS, Chunky.

## No 26.1 NeoForge release found

These need a replacement, an upstream port, or deferral:

- **Core gameplay:** Hostile Neural Networks, Ars Nouveau, Farmer's Delight, Supplementaries, Quark, Handcrafted, Cosmetic Armor Reworked, Time in a Bottle, Torchmaster, OpenBlocks Elevator, Akashic Tome.
- **UI/general:** Polymorph, Equipment Compare, Light Overlay, Configured, Overloaded Armor Bar, Observable.
- **World/content:** L_Ender's Cataclysm, Simple Tomb, Almost Unified.
- **Building:** Building Gadgets 2 was not verified and `Building Gadgets 2 GUI` is not a separate release; treat both as unavailable until the project publishes a matching file.

## Must verify through the publisher's CurseForge/GitHub releases

No unambiguous matching Modrinth record was located for Flux Networks, Compact Machines, FTB Chunks, FTB Ultimine, Allthemodium, ATO/All the Ores, Building Gadgets 2, Just Enough Beacons, Extreme Sound Muffler, AllTheLeaks, or a backup mod. They are **not confirmed compatible**; pin them only after checking an exact 26.1 NeoForge file.

Also verify the remaining requested YUNG's modules individually: Better End Island, Jungle Temples, Strongholds, Desert Temples, and Extras were not in the confirmed set above.

## Required dependencies and constraints

- AE2 Wireless Terminals requires AE2; the current AE2 line also requires GuideME.
- Powah and Functional Storage require Titanium; Powah also requires Cloth Config API.
- Mystical Agriculture requires Cucumber Library.
- Apotheosis requires Apothic Enchanting, Apothic Spawners, Apothic Attributes, Patchouli, and Placebo.
- Keep client-only rendering/UI mods off the dedicated server unless their own metadata permits server loading. This particularly affects Sodium/Iris and UI, culling, FPS, zoom, and overlay mods.
- NeoForge and Fabric jars are not interchangeable.

## Recommended workflow

Use [packwiz](https://packwiz.infra.link/) as the closest practical equivalent to Nix flakes: commit `pack.toml` plus per-mod TOML metadata and pinned hashes to Git. Install with its Modrinth/CurseForge integrations, review every selected file's loader/game-version/dependencies, and export a Modrinth or CurseForge pack. It makes the pack reproducible, but it is not a complete cross-mod compatibility solver.

Start with an empty 26.1 NeoForge instance, add only the confirmed core mods and dependencies, launch both client and dedicated server, then add one subsystem at a time. Do world-generation mods before creating a long-lived world.
